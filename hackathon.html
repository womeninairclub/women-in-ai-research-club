How it works

Two-stage format

Only teams selected through Stage 1 proceed to the main development round.

01

Idea Screening — 19 October

Participants select a published problem statement and submit their proposed solution.

  • Problem understanding
  • Proposed solution
  • Innovation / novelty
  • AI / technology approach
  • Expected impact
  • Brief implementation plan
02

Main Hackathon — 20 October

Shortlisted teams develop and implement their proposed solutions within the designated development period.

  • Develop and test the solution
  • Maintain the GitHub repository
  • Complete the README and documentation
  • Prepare the demonstration and pitch
  • Submit through the official process

Participation

Team & development rules

Key requirements from the official Rules & Regulations.

Team Formation

  • Individual participation or teams are allowed.
  • Maximum team size: 4 participants.
  • Each team must designate one Team Leader.
  • A participant may belong to only one competing team.
  • Team members must be declared during registration / idea submission.

Development

  • Main development must happen within the designated hackathon development period.
  • AI-assisted development tools are permitted with appropriate disclosure where required.
  • Entirely pre-built projects cannot be submitted.
  • Open-source libraries, APIs, public datasets and pretrained models may be used where legally permitted.
Final Submission

GitHub + official submission

The GitHub repository and official submission form together constitute the final submission.

GitHub Repository

  • Source code
  • README.md
  • Requirements / dependencies
  • Installation and usage instructions
  • Dataset and model information
  • Screenshots / demo information
  • Credits and attributions

README should include

  • Team and problem details
  • Proposed solution and key features
  • Technology stack and methodology
  • Architecture / workflow
  • Results and limitations
  • Future scope
  • External resources / attributions

What judges will consider
