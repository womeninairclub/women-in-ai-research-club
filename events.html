About the Hackathon

The AI Innovation Hackathon 2026 is an online, international hackathon organized by the Women in AI, Research, Innovation & Entrepreneurship Club to encourage innovation, creativity, problem-solving and the practical application of Artificial Intelligence and related technologies.

Hackathon Format

Two-Stage Process

01

Stage 1 — Idea Screening

Participants review the published problem statements and submit or pitch their proposed solution ideas.

  • Team name
  • Team members
  • Selected problem statement
  • Problem understanding
  • Proposed solution
  • Innovation / novelty
  • Proposed technology / AI approach
  • Expected impact
  • Brief implementation plan
02

Stage 2 — Main Hackathon

Selected teams advance to the final round and develop their proposed solutions during the designated hackathon development period.

  • Develop the proposed solution
  • Build and test the project
  • Maintain the GitHub repository
  • Complete documentation
  • Prepare the demonstration
  • Submit the final project

Final Round

Final Submission

The GitHub repository and official submission form together constitute the final submission.

GitHub Repository

Each final-round team must maintain its project in a GitHub repository accessible to the judges.

  • Source code
  • README.md
  • Requirements / dependencies
  • Installation instructions
  • Usage instructions
  • Documentation
  • Dataset information
  • Model information
  • Screenshots
  • Demo information
  • Credits / attributions

Final Submission Includes

  • GitHub repository URL
  • Team details
  • Selected problem statement
  • Project description
  • Demo link / video, where applicable
  • Required documentation
  • Other information requested by the organizers

The official final project submission form will be provided by the organizing team.

Evaluation

Judging Criteria

Problem Understanding

How clearly the team understands the assigned challenge.

Innovation

Originality and creativity of the solution.

Technical Implementation

Quality and appropriateness of the implementation.

Use of AI

Meaningful and appropriate use of AI/ML or related technologies.

Functionality

How effectively the proposed solution works.

Practicality & Impact

Potential real-world usefulness and impact.

Scalability

Potential for further development or deployment.

Presentation

Clarity of documentation, demonstration and final pitch.

Responsible AI

Use of AI Tools

AI-assisted development tools are permitted for brainstorming, coding assistance, debugging, research, documentation, development support and code explanation.

Participants remain responsible for their final submission. Participants must understand their project and be able to explain their implementation to the judges.

Significant use of AI tools should be disclosed where requested by the organizers.
